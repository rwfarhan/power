# 📊 Sales Analysis Dashboard (Power BI)

## 📌 Project Overview

This project presents an interactive **Sales Analysis Dashboard** built using **Power BI**. It provides insights into sales performance, profit trends, customer segments, and regional distribution.

The dashboard helps stakeholders make data-driven decisions by visualizing key business metrics in a clear and interactive format.

---

## 🎯 Objectives

* Analyze overall **sales performance**
* Track **profit, quantity, and discount trends**
* Compare performance across **regions, categories, and segments**
* Identify **top-performing products**
* Monitor **monthly and yearly trends**

---

## 📁 Dataset

* Dataset Name: `super_store`
* Contains:

  * Customer details
  * Product categories & sub-categories
  * Sales, Profit, Quantity, Discount
  * Order & Shipping information
  * Region & Segment data

---

## 📊 Key Dashboard Features

### 🔢 KPIs

* **Total Profit**: 286.4K
* **Total Sales**: 2.3M
* **Total Quantity**: 37.9K
* **Total Discount**: 1.6K

---

### 📍 Filters / Slicers

* Region: Central, South, East, West
* Year: 2014, 2015, 2016, 2017

---

### 📈 Visualizations

* Sales by Category (Bar Chart)
* Monthly Sales Trend (Line Chart)
* Sales vs Profit (Scatter Plot)
* Category Profit Distribution (Pie Chart)
* Treemap for Category Sales
* Sales by Ship Mode (Donut Chart)
* Sales by Segment (Donut Chart)
* Sales by Quarter (Donut Chart)
* Geographic Map (Sales Distribution)
* Top 10 Products Table

---

## 🛠 Tools & Technologies

## 📌 Insights

* Technology category generates the highest sales
* Consumer segment contributes the largest share
* Standard Class shipping is most used
* Sales show growth trend across months
* Certain products contribute significantly to revenue

---

## 🚀 How to Use

1. Open the `.pbix` file in Power BI Desktop
2. Use slicers (Region, Year) to filter data
3. Hover over visuals for detailed insights
4. Explore different charts for trends and comparisons
